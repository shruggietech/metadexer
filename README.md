# metadexer

Content-addressed asset management with deep metadata search, hybrid storage
routing, and temporal observation tracking.

> **Status:** Pre-release / In Development

metadexer manages large, heterogeneous collections of digital data. It indexes
files using shruggie-indexer, stores content in a deduplicated vault, and
catalogs rich metadata for search and retrieval.

## Requirements

- Python 3.12+

## Development Setup

```bash
./scripts/venv-setup.sh
```

On Windows:

```powershell
.\scripts\venv-setup.ps1
```
