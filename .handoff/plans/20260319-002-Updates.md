## 1. Purpose and Context

This is the first implementation sprint for the metadexer project. It creates the complete repository skeleton defined in §10 of the specification: all directories, configuration files, source package stubs, test infrastructure, documentation site scaffolding, and agent context files. No functional code is produced. The deliverable is an empty but structurally complete, installable Python package that passes linting and an initial test suite.

This sprint also retires the `_TEMPLATE.txt` session prompt template convention from the development workflow. The sprint document itself is the single artifact consumed by coding agents, incorporated by reference. The specification update directive (Item 6) formalizes this change in `metadexer-spec.md`.

All work items reference specification sections by number. The specification (`metadexer-spec.md` at repository root) is the authoritative source for every structural and behavioral detail. When this sprint document and the specification conflict, the specification wins, except where this document explicitly declares a deviation (see Item 3, agent context file comment text, and Item 6, specification amendments).
